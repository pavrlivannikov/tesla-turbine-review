# Турбина Теслы — переосмысление для современных рабочих тел

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
![Status: Research](https://img.shields.io/badge/Status-Research-blue)

Анализ патента Теслы US 1,061,206 (1913) с математическим моделированием и подбором современных рабочих тел. Открытый исследовательский проект.

## Ключевые результаты

- **Математическая модель** (Python) — полный расчёт турбины, 6 рабочих тел, 3 конфигурации
- **Пограничный слой равновесен** при макроскопических зазорах — турбина работает как тепловая машина, а не кинетический сепаратор
- **Практические применения:**
  - 🏠 Котёл ГВС → 480 Вт электричества (питает насос, свет, холодильник)
  - 🚗 Выхлоп ДВС → 2.6 кВт (бортовая электроника, экономия 390 л/год)
  - 🔥 Автономный газовый генератор → 1 кВт (50 дБ, в 2-5 раз дешевле аналогов)
- **Лучшее рабочее тело — FC-770:** 9 154 RPM (рекордно низкие обороты), стабилен до 400°C
- **Шумность 50-55 дБ** — тише инверторных Honda (47-60 дБ)

## Быстрый старт

```bash

```
